
# 🎓 EduForge — منصة بناء المنصات التعليمية (التصور الكامل)

> **الفكرة بسطر واحد:** Shopify للتعليم — أي شخص يقدر يبني منصة تعليمية احترافية كاملة (مثل Udemy/Thinkific) في أقل من 5 دقائق، بدومين خاص، ومعزولة تماماً عن باقي المنصات.

---

## 1. الجمهور المستهدف

| الفئة | الاستخدام |
|------|----------|
| **المعلم الفردي** | يبيع دوراته الخاصة بهويته |
| **الأكاديميات** | منصة متكاملة بمعلمين متعددين |
| **الشركات** | تدريب موظفين (Corporate LMS) |
| **المدارس/الجامعات** | فصول إلكترونية مكملة |

---

## 2. المعمارية العامة (Multi-Tenant)

```text
┌─────────────────────────────────────────────────┐
│         EduForge Super Admin (نحن)              │
│   إدارة المستأجرين، الفوترة، الإحصائيات         │
└─────────────────────────────────────────────────┘
              │
   ┌──────────┼──────────┬──────────┐
   ▼          ▼          ▼          ▼
 منصة 1    منصة 2    منصة 3    منصة N
(دومين      (دومين     (دومين    (sub
 خاص)       فرعي)      خاص)      domain)
   │          │          │          │
   ▼          ▼          ▼          ▼
 [طلاب + معلمين + محتوى + بيانات معزولة 100%]
```

**العزل:** كل منصة لها:
- مستخدمون منفصلون (Row-Level Security حسب tenant_id)
- تخزين سحابي معزول (مجلد/Bucket خاص)
- إعدادات وهوية بصرية مستقلة
- بيانات وتحليلات منفصلة

---

## 3. الأدوار (4 طبقات)

1. **Super Admin** (نحن) — يدير كل المنصات والاشتراكات
2. **Tenant Owner** (صاحب المنصة) — يدير منصته بالكامل
3. **Instructor** (معلم) — ينشئ ويدير دوراته
4. **Student** (طالب) — يتعلم ويتفاعل

---

## 4. الميزات الكاملة (حسب المستخدم)

### 🏢 لـ Super Admin (لوحة تحكم EduForge)
- إدارة جميع المستأجرين (تفعيل/تعليق/حذف)
- خطط اشتراك (Free / Starter / Pro / Enterprise)
- فوترة تلقائية + تجديد + إيقاف عند عدم الدفع
- إحصائيات شاملة (MRR, Churn, عدد المنصات النشطة)
- إدارة الكوبونات العامة
- مراقبة الاستخدام (تخزين، AI tokens، البث)

### 🎨 لـ Tenant Owner (Builder + Dashboard)

**أ) منشئ المنصة (No-Code Builder):**
- اختيار قالب جاهز (10+ قوالب)
- تخصيص الألوان، الخطوط، اللوغو
- بناء الصفحات بـ Drag & Drop
- صفحة هبوط، عن المنصة، الدورات، التواصل، المدونة
- معاينة فورية (Mobile/Desktop)

**ب) إعدادات المنصة:**
- ربط دومين مخصص + SSL تلقائي
- لغات: عربي/إنجليزي (RTL/LTR)، قابل للتوسع
- بوابات دفع: Stripe / Paddle / PayPal / STC Pay / Tap / HyperPay
- عملات متعددة
- ضرائب VAT تلقائية
- إعدادات البريد (SMTP مخصص أو افتراضي)
- Webhooks للتكامل مع أنظمة خارجية

**ج) إدارة المحتوى:**
- إدارة الدورات، الفصول، الدروس
- إدارة المعلمين (دعوة، صلاحيات، نسبة الأرباح)
- إدارة الطلاب (تسجيل يدوي، استيراد CSV، تجميع بفئات)
- المدونة (Blog) + SEO
- إدارة الشهادات (Certificates) — تصاميم مخصصة

**د) المبيعات والتسويق:**
- كوبونات خصم (نسبة/مبلغ، حد استخدام، تاريخ انتهاء)
- باقات (Bundles) — عدة دورات بسعر واحد
- اشتراكات شهرية/سنوية (Membership)
- نظام Affiliate (تسويق بالعمولة)
- Email Marketing (حملات، Drip campaigns)
- نوافذ Upsell / Cross-sell
- Abandoned Cart Recovery

**هـ) التحليلات:**
- إيرادات، عدد الطلاب، معدل الإكمال
- خرائط حرارية للفيديوهات (أين يتوقف الطلاب)
- تقارير قابلة للتصدير (PDF/Excel)

### 👨‍🏫 لـ Instructor

- إنشاء دورة (عنوان، وصف، سعر، صورة، فيديو ترويجي)
- **بنية الدورة:** فصول → دروس (فيديو/صوت/PDF/نص/كويز)
- رفع فيديوهات (تشفير تلقائي، جودات متعددة، حماية من التحميل)
- **بث مباشر** (Live Streaming) — جلسات مجدولة + تسجيل تلقائي
- اختبارات إلكترونية (MCQ، صح/خطأ، مقالي، رفع ملف)
- واجبات + تصحيح
- منتدى نقاش لكل دورة
- محادثة مباشرة مع الطلاب (Chat)
- جدولة جلسات 1-on-1
- إحصائيات أداء الطلاب

### 🎓 لـ Student

- تسجيل/دخول (Email/Google/Apple)
- تصفح وشراء الدورات
- مشغل فيديو متقدم (سرعة، ترجمة، علامات مرجعية)
- **المرشد الذكي (AI Tutor) لكل فيديو** — يفهم محتوى الفيديو ويرد على الأسئلة
- ملاحظات شخصية على الفيديو (مع timestamp)
- تتبع التقدم + شهادة عند الإكمال
- محادثة مع المعلم
- منتدى الدورة
- محفظة + سجل المشتريات
- تطبيق Mobile (PWA في البداية، Native لاحقاً)

## 7. الـ Stack التقني المقترح

| الطبقة | التقنية |
|--------|---------|
| Frontend | TanStack Start (React 19 + SSR) |
| Backend | Server Functions + Server Routes |
| Database | Supabase (Postgres + RLS للعزل) |
| Auth | Supabase Auth (Email/Google/Apple) |
| Storage | Supabase Storage (Buckets/tenant) |
| Video | Mux أو Cloudflare Stream (تشفير + HLS) |
| Live | Daily.co أو 100ms |
| Payments | Stripe Connect (Multi-tenant) + Paddle |
| AI | Lovable AI Gateway (Gemini/GPT) + AssemblyAI |
| Email | Resend |
| Domains | Cloudflare for SaaS (Custom domains + SSL تلقائي) |
| Search | Postgres FTS + pgvector للبحث الدلالي |
| Analytics | Self-hosted + PostHog |

---

## 8. التحديات التقنية الرئيسية

1. **عزل البيانات (Multi-Tenancy):** RLS صارمة على `tenant_id` في كل جدول
2. **الدومينات المخصصة:** Cloudflare for SaaS + توجيه ديناميكي
3. **حماية الفيديوهات:** تشفير + Signed URLs + DRM
4. **توسعية البث المباشر:** WebRTC SFU
5. **تكلفة الـ AI:** Cache + Rate limiting حسب الخطة
6. **الفوترة المتعددة:** Stripe Connect لتوزيع الأرباح

## 11. الخطوة التالية المقترحة

أنصح نبدأ بـ **MVP محصور جداً**:
- منصة واحدة فقط (بدون multi-tenant في البداية)
- معلم → دورات → فصول → دروس فيديو → طلاب → دفع
- بدون AI، بدون بث، بدون دومين مخصص

ثم نضيف الـ multi-tenancy في المرحلة الثانية بعد التأكد من نموذج العمل.

**هل توافق على هذا التصور؟ أم تريد تعديل/إضافة/حذف أي ميزات قبل ما نبدأ بناء MVP؟**
